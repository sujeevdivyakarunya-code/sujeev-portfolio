# AI Portfolio Generator — Shareable Template

## Already included
- AGENTS.md and Antigravity rules/workflows
- portfolio/design/UX/motion knowledge
- Framer-inspired reference guidance
- curated Behance reference links + analysis files
- premium portfolio reference manifests
- portfolio input structure
- `prompt.txt` master kickoff prompt

## Optional manual downloads
Only four external codebases are optional. They are not bundled because they are third-party repositories and should be obtained directly from their official GitHub sources.

1. https://github.com/aitezazdev/Portfolio
   → `references/codebases/aitezaz/`
2. https://github.com/fGiordi/portfolio-framer-motion
   → `references/codebases/dennis-style/`
3. https://github.com/uxderrick/marginalia
   → `references/codebases/marginalia/`
4. https://github.com/hafsa-Webdeveloper/Portfolio-Web
   → `references/codebases/hafsa/`

Everything else is already included.

## How to share/use
1. Extract the ZIP.
2. Open the extracted folder in Google Antigravity.
3. Put the creator's work inside `portfolio/`.
4. Optionally download the four reference repos above.
5. Open `prompt.txt`, paste it into the IDE agent, and start discovery.
6. Answer the agent's questions and let it build/review the site.

`project.md` is optional. Normal users can simply drop their existing files into `portfolio/`.
