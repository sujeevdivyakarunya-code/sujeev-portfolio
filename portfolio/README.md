# Portfolio Source Folder

Recommended structure:

portfolio/
├── profile/
│   ├── bio.md
│   ├── profile-image.jpg
│   └── resume.pdf
├── projects/
│   ├── project-01/
│   │   ├── project.md
│   │   ├── cover.jpg
│   │   └── media/
│   └── project-02/
└── assets/

This structure is recommended, not mandatory. The AI must also handle messy folders and infer
organization from filenames, file types, documents, and media.

The AI must never turn an uncertain inference into a factual claim.
