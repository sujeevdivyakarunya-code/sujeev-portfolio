## Description
Designed a complete mobile application interface from concept to interactive prototype for an on-demand organic vegetables and fresh produce delivery service.

## UX Intervention & Solution
- Conducted user needs analysis focusing on freshness transparency, intuitive farm-to-table filtering, simple basket management, and seamless 3-step checkout.
- Developed an earthy, vibrant, and clean design system with custom card components, category chips, and visual price-per-weight hierarchy.
- Constructed a complete high-fidelity clickable prototype in Figma demonstrating browse, search, product detail, cart, and payment confirmation flows.

## Outcome
- Complete end-to-end multi-screen mobile app system with coherent design language.
- Interactive Figma prototype validated through user journey testing.
