## Description
Conducted comprehensive, 'why'-driven heuristic teardowns of industry-leading apps Blinkit (quick commerce) and Spotify (audio streaming), decoding UX decisions behind information density, contrast, and navigation priority.

## UX Intervention & Solution
- Analyzed quick-commerce conversion patterns in Blinkit: banner priority, sticky search bar, visual urgency cues, and micro-cart interactions.
- Examined Spotify's dark-mode typography rhythm, dynamic color extraction algorithms, and playlist browsing ergonomics.
- Faithfully recreated the Blinkit home screen in Figma to master precise component auto layout, spacing tokens, and responsive padding.

## Outcome
- Published structured UX teardowns establishing evidence-based design reasoning.
- Deepened proficiency in high-density UI component architecture.
