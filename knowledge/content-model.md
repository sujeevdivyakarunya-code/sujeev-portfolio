# Content Model

Profile fields may include: name, headline, profession, location, bio, profile image, resume,
email, and social links.

Project fields may include: title, category, client, year, description, role, services, tools,
outcome, metrics, cover, media, project URL, source URL, and featured.

Evidence rules:
- Explicit supplied text is strong evidence.
- Supplied documents and links are strong evidence.
- Visual inference is weaker evidence.
- Never convert a guess into a factual claim.

When `project.md` exists, use it as the project's metadata source.
