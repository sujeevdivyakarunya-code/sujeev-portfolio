## What "Framer-Like" Means

Do not copy any Framer template literally.

Extract these qualities:

1. Visual storytelling — the page feels like a sequence, not static sections.
2. Strong typography — type is a major part of the visual identity.
3. Large media — real work receives substantial visual space.
4. Intentional whitespace — spacing creates rhythm.
5. Scroll choreography — sections reveal, transform, pin, overlap, or transition purposefully.
6. Rich hover states — interactions feel tactile but remain subtle.
7. Sticky/pinned moments — useful for project narratives and case studies.
8. Variable scale — featured work should not have the same visual weight as every other item.
9. Minimal UI chrome — navigation supports the work.
10. Responsive art direction — mobile is intentionally composed, not merely stacked.

## Framer-Inspired Motion

Consider:
- mask/text reveals
- staggered project entrances
- subtle image scale
- media parallax
- sticky section transitions
- clip-path reveals
- hover transformations
- background movement
- smooth navigation transitions

Do not use all of them. Select based on the creator and content.

## Interaction Ideas

When appropriate:
- magnetic CTA buttons
- subtle cursor states
- project hover previews
- image movement
- directional arrows
- scroll progress
- sticky project information
- lightbox media
- fullscreen viewing

Keep interactions understandable, accessible, and performant.

## Do Not Copy

Never copy exact layouts, typography combinations, colors, animations, wording, component
arrangements, or proprietary assets.

Use these references to understand the polish and interaction quality expected from strong
Framer portfolios.

## Quality Target

Aim for the feeling of a thoughtfully art-directed Framer portfolio:

content intelligence
+ strong art direction
+ large visual media
+ premium typography
+ smooth interaction
+ responsive composition
+ fast performance

The goal is not "more animation." The goal is a better visual experience.
