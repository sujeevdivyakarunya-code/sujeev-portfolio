# Web Interface Guidelines

Use semantic HTML and accessible native controls.

Keyboard: every flow must be keyboard-operable and focus states must remain visible.

Mobile: prevent horizontal overflow, use comfortable touch targets, and test long content.

Motion: respect prefers-reduced-motion; prefer transform/opacity; avoid transition: all.

Typography: clear hierarchy, readable line length, graceful long titles.

Media: reserve dimensions, lazy-load non-critical media, prioritize important media, avoid layout shift.

Interaction: use links for navigation and buttons for actions; provide useful labels and states.

Content: concise labels, actionable errors, meaningful empty states, robust handling of user content.
