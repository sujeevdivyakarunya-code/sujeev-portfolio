# AI Portfolio Generator

A shareable Antigravity starter for turning a creator's portfolio folder into a premium, profession-aware portfolio website.

Start with `SHARE-README.md`, then use `prompt.txt`.

Key folders:
- `portfolio/` — creator's actual files
- `knowledge/` — design, UX, content and quality context
- `references/` — premium web, code and Behance references
- `.agents/` — agent rules/workflows
- `AGENTS.md` — primary project rules
